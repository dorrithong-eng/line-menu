# LINE 圖文選單管理 — 互動 Prototype

Social CRM 後台的 **LINE 圖文選單（Rich Menu）設定與管理** 功能原型。純前端、零相依套件，直接用瀏覽器開啟 `index.html` 即可操作（無需編譯或啟動伺服器）。

## 如何開啟

- 直接雙擊 `index.html`，或
- 於資料夾內啟動任一靜態伺服器，例如：`python3 -m http.server` 後開啟 `http://localhost:8000`

## 檔案結構

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 進入點 |
| `styles.css` | 樣式 |
| `app.js` | 全部互動邏輯（原生 JavaScript，無框架） |

## 功能對應

### 左側 Panel
- **預設圖文選單**：固定一組，所有未被指定選單／新加入的會員皆看到此選單。
- **一般圖文選單**：可無限新增（`＋`），可透過發送功能指定給會員；亦可作為其他選單「切換選單」的目標。
- 每個一般選單的 `⋯` 選單：**重新命名、複製、移除所有套用、下載會員資料、刪除**。
  - 「移除所有套用」「下載會員資料」於本 prototype 僅為示意，不執行實際行為。

### 中間區塊 — 排程卡片
- 點選任一選單，顯示該選單下所有排程，每張卡片含：名稱、圖片預覽、時間、狀態。
- 狀態：**常駐 / 已下檔 / 使用中 / 排程中**（以固定「今天 = 2026-07-07」推算，種子資料對齊示意圖）。
- 每張卡片可 **編輯**；非常駐卡片可 **刪除**。
- 右上「**＋ 新增排程**」進入設定頁。

### 常駐內容
- 每個一般選單建立時，預設含一張 **常駐** 卡片（選填內容）。
- 常駐內容 **不可刪除、不可設定時間**；當排程時間無內容時顯示常駐內容。

### 設定頁（新增／編輯排程）
- 排程名稱、排程時間、選方下單顯示文字、預設展開（好友進入時自動展開）。
- **排程時間不可與同一選單內其他排程重疊**（存檔時驗證，重疊會出現錯誤提示）。
- 圖片以純色區塊示意；每個切割「格子」可設定點擊行為：
  - **傳送文字 / 開啟連結 / Postback**（輸入內容）
  - **切換選單**（下拉選擇已建立的其他選單，實現 A 選單 → B 選單）
- 格子可上移／下移／複製／刪除。

## 預載資料（對齊示意圖）
- **預設圖文選單**：4 個排程（常駐 + 寒假 / 暑假 / 開學）。
- **A 選單、C 選單**：僅一張空白常駐內容。
- **B 選單**：6 個排程（常駐 + 兒童節 / 母親節 / 父親節 / 教師節 / 萬聖節）。

> 注意：`今天` 於程式中固定為 `2026-07-07`（`app.js` 的 `TODAY`），使種子資料的狀態徽章與示意圖一致。
